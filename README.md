# Cake Cafe Premium Website

A multi-page React + Vite website for Cake Cafe — The Tasty Bakery, Chintal, Hyderabad.

## Pages
- Home
- Menu
- Custom Cake Inquiry
- Our Story
- Gallery
- Visit Us

## Features
- Responsive design system with reusable components
- React Router multi-page navigation
- Premium editorial bakery visual direction
- Category-filtered menu
- Cake inquiry form that opens WhatsApp
- Gallery lightbox
- Scroll reveal and sticky header
- SEO metadata, accessible navigation, reduced-motion support
- Production build via Vite

## Run locally
1. Install Node.js (LTS).
2. Extract this project.
3. Open a terminal in the project folder.
4. Run `npm install`
5. Run `npm run dev`
6. Open the local URL shown by Vite.

## Build
Run `npm run build`. The production site is generated in `dist/`.

## Before publishing
Replace sample photography with approved Cake Cafe images. Verify current menu, prices, hours, rating/review count, testimonials, phone and WhatsApp number. Current order flow is an inquiry handoff to WhatsApp; no payment or order-management backend is included.
